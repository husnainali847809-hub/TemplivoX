How to use this template

  1. Download the PDF to print, or the editable file to fill in on a computer.
  2. List the main tasks, give each one an owner and a due date, then update the status each week.
  3. Print at 100 percent scale on A4 or US Letter paper, or save your edited file as a PDF.

It suits small projects and personal plans. Large projects usually need dedicated project management software.
